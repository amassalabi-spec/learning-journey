# 🐍 Python Fundamentals

> **Premiers pas en Python** — Configuration environnement, syntaxe de base, structures de contrôle.

## 📋 Contenu

- **Installation & Setup** : Python 3, VS Code, environnements virtuels (`venv`), `pip`
- **Syntaxe de base** : Variables, types de données, opérateurs
- **Structures de contrôle** : `if/elif/else`, boucles `for`/`while`, compréhensions
- **Fonctions** : Définition, arguments, portée, fonctions lambda
- **Modules & Packages** : `import`, packages standards (`os`, `sys`, `json`, `datetime`), pip packages tiers

## 🎯 Objectifs d'apprentissage

- [x] Environnement de développement opérationnel
- [x] Écrire et exécuter des scripts Python
- [x] Manipuler les types de base (str, int, float, bool, list, dict, set, tuple)
- [x] Contrôler le flux d'exécution
- [x] Structurer le code en fonctions réutilisables
- [x] Gérer les dépendances avec `pip` et `requirements.txt`
