# 📊 Data Science Labs

> **Introduction aux Applications Data** — Manipulation, nettoyage, visualisation et analyse exploratoire.

## 📋 Contenu

- **Pandas** : `DataFrame`, `Series`, lecture/écriture (CSV, Excel, JSON, Parquet), indexation, jointures
- **NumPy** : Tableaux multidimensionnels, opérations vectorisées, broadcasting
- **Visualisation** : Matplotlib, Seaborn — graphiques statistiques, distributions, corrélations
- **Nettoyage données** : Valeurs manquantes, doublons, types, outliers, feature engineering basique
- **EDA (Analyse Exploratoire)** : Statistiques descriptives, visualisation multidimensionnelle, insights

## 🎯 Objectifs d'apprentissage

- [x] Charger et inspecter des datasets variés
- [x] Nettoyer et préparer des données pour l'analyse
- [x] Créer des visualisations informatives
- [x] Extraire des insights business à partir de données brutes
- [x] Documenter le processus dans des notebooks Jupyter

## 🛠 Stack

| Outil | Usage |
|-------|-------|
| `pandas` | Manipulation données tabulaires |
| `numpy` | Calcul numérique performant |
| `matplotlib` / `seaborn` | Visualisation statique |
| `plotly` | Visualisation interactive (optionnel) |
| `jupyter` | Notebooks interactifs |
